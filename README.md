# Burn

Know your Claude Code burn rate. Burn is a Mac app that reads your local Claude Code logs and shows where your tokens go: your 5-hour and 7-day limits, token history, projects, a week plan, your agents, and a live view of what Claude is doing right now. Everything stays on your Mac.

![Burn](https://github.com/unpaidfunds/Burn/releases/download/v1.1-beta/burn-now.png)

## Features

- **Limits:** your 5-hour and 7-day usage with reset times. Exact when you're signed in to Claude Code, a live ≈ estimate otherwise.
- **History:** a daily heatmap, weekly bars, and all-time totals. Add usage from an old account by hand.
- **Projects and plan:** where your tokens went, and how to spread the rest of your week.
- **Agents:** a node graph of your agents with each one's real spend, budget and warnings.
- **tokenmaxxing:** your real Claude Code activity as a live editor, terminal and chat.
- **Themes:** Claude Code, Code and Ember. Works in split screen.

## Install

1. Download the `.zip` from the [Releases page](https://github.com/unpaidfunds/Burn/releases).
2. Unzip it and drag `Burn.app` into Applications.
3. The app is unsigned. Right-click it, choose **Open**, then confirm. Or run once:

```sh
xattr -cr /Applications/Burn.app
```

Requires an Apple Silicon Mac.
