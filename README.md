# Burn

Know your Claude Code burn rate. Burn is a Mac app that reads your local Claude Code logs and shows your token usage: an all-time heatmap, this week against your limit, a session meter, and an agent pipeline where each agent has its own model, budget and warnings.

## Install

1. Download `Burn-0.1.0-beta-mac.zip` from the latest release on this page.
2. Unzip it and drag `Burn.app` into Applications.
3. The app is unsigned. Right-click it, choose **Open**, then confirm. Or run once:

```sh
xattr -cr /Applications/Burn.app
```

Requires an Apple Silicon Mac.
